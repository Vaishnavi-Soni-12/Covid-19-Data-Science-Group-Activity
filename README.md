# COVID-19 End-to-End Data Science Project

## Overview
This project provides a comprehensive, data-driven analysis of the COVID-19 pandemic. It explores the causes, spread, global outcomes, and the impact of interventions like vaccinations and government restrictions.

## Project Structure
- `data/`: Contains raw and processed datasets.
- `analysis/`: Python scripts for data processing and exploratory data analysis (EDA).
- `report/`: The final formal report and visualization assets.
- `docs/`: Additional documentation for GitHub.

## Features
- **Data Cleaning**: Comprehensive handling of missing values and data inconsistencies.
- **15+ Visualizations**: Detailed graphs covering mortality, spread, vaccination, and economic factors.
- **Detailed Corporate Report**: A high-fidelity Word (.docx) document with formal sections (Introduction, Objective, Results, Analysis, Discussion).
- **Data Explanations**: Every one of the 16 analytical graphs includes a detailed interpretation of the trends and outliers.
- **Academic Standards**: Times New Roman font, black text, and justified alignment throughout.
- **Impact Analysis**: Quantitative assessment of vaccine efficacy and regional outcomes.

## How to Run
1. Ensure Python 3.8+ is installed.
2. Install dependencies: `pip install pandas matplotlib seaborn requests`
3. Run `analysis/data_processing.py` to fetch and clean the data.
4. Run `analysis/covid_analysis.py` to generate the visual analysis.
5. View the final report in `report/COVID19_Report.md`.
